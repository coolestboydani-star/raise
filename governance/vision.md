# Solution Vision: RaiSE

## Identity

### Description

RaiSE is an open-core governance framework and CLI for AI-assisted software engineering. It persists workflow state, runs deterministic quality checks between phases, and keeps the artifacts and context behind software changes portable across coding tools.

## Outcomes

| **Outcome** | **Description** |
|-------------|-----------------|
| **Reliable delivery** | Developers can use AI coding tools while tests, lint, types, and workflow gates remain executable and observable. |
| **Traceable work** | Decisions, scope, session context, and validation evidence remain available across sessions and tools. |
